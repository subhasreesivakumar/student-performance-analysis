
# Student Performance Data Analysis

**Created by:** Subhasree S.  
**Course:** BSc Computer Science with AI and Data Science

## About
A beginner-friendly Python project that analyzes student marks and generates a performance summary.

## Features
- Display student marks
- Calculate total and average marks
- Identify the highest scorer
- Display pass or fail status

## Concepts Used
- Python lists and dictionaries
- Loops and conditional statements
- Arithmetic operations
- Data analysis fundamentals

## Technology
Python 3

## Learning Outcome
Learned how to organize data, calculate statistics, and generate a simple report using Python.
